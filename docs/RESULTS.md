## Held-out mutants (operator families frozen before running)

Dev mutants (operator swaps, constant bumps, deleted calls) were used while fixing the checks. Held-out mutants use families we never tuned on: string literal changes, and/or swaps, argument swaps, and a neutralised SQL predicate. Rule: no check may be changed because of a held-out result without moving that family into dev and adding a new held-out family.

- 18 held-out mutants: 12 returned with proof (67%), 6 routed to a human, 0 passed as light. Small set: treat it as a smoke test, not a precise rate.

## Human spot checks

Policy: full read of 20% of light-lane PRs, chosen at random. Of 7 light-lane PRs, picked MUT-025; misses found: MUT-025. A miss found this way counts as an escape in the trust ledger, so the area loses its light lane.

## Optional LLM reviewer (gemini-3.8-flash, advisory only)

- 11 findings on the 13 PRs; 0 dropped by the quote check (hallucination rate 0%).
- Pointed at the planted bug's file on 8/8 buggy PRs, including PR-109, which the deterministic checks only route as a question.
- Hand-labelled: 8 of 11 claims were correct. Wrong ones: PR-110: true of main too; not introduced by this refactor; PR-111: wrong: TransferError is defined in the same module; the acceptance tests pass; PR-113: out of scope for a copy change; another PR builds AC2.
- Lesson: every wrong claim quoted real code, so grounding filters invented code, not wrong reasoning. That is why LLM findings route attention and never block.

## Side by side with AI code reviewers on the same 13 PRs

Each sample PR is a real pull request on GitHub (captured 2026-11-14T14:05Z). GitHub Copilot review was requested on all 13; refused every one for insufficient quota.

- **PR Trailer:** 8/8 planted bugs, 7 of them reproduced and returned to the agent with evidence.
- **Gemini (our advisory LLM pass):** pointed at 8/8, as opinion.
- **Devin Review:** 4/8 visible on GitHub, plus a 'security issue' on the other 4 whose text Devin keeps on its own dashboard.
- **Codex:** 3/8, but it had only reviewed 5 of the 13 PRs when captured, and it caught every planted bug in the ones it did review.

Our reading: on bugs this size, good AI reviewers find most of them too, so catch rate is not where the trailer wins. It wins on what the approver gets. A reviewer comment is an opinion to re-check. The trailer reproduces the failure, returns the PR to the agent without a human, answers "does it do anything else?", and puts every clean PR in a lane, so the approver knows how much to read. Reviewer comments can feed the trailer as advisory items, like Gemini today.
