Approve the outcome, not the diff.

The person who approves an AI-written change is accountable that it does what it should, and nothing else. PR Trailer starts from that outcome. It shows the evidence that the code meets it, flags anything changed outside it, and lists the few spots worth your eyes, with a confidence level for each area. It also shows what the AI refused to decide, and how dangerous the merge is. The AI never approves. Only problems it can reproduce are allowed to block.

Because we also wrote the checks, we generated mechanical mutants of the bank code as a second, unbiased test, each submitted as a "tidy-up, no behaviour change" PR. Principles

Evidence over confidenceThere are no confidence scores. Every claim is either re-runnable evidence or marked as advice.
Only reproduced problems blockTests, probes, invariants and counterexamples decide. Static rules and LLM opinions only route attention.
Trace to the requirementTests are named REQ_ID.test_acN. A criterion with no test becomes an open question, never a silent pass.
Refuse out loudIntent, security logic, data destruction and unprovable equivalence go to a named human, with the exact question.
Depth follows dangerLane by door type and blast radius, not by lines changed. A two-line DROP COLUMN gets a full read.
Trust is earned per areaLight checks unlock after a clean streak in an area. One escape forces full reads for the next five PRs.
LLMs must quoteAn LLM finding must quote the line it is about. If the quote isn't in the PR, the finding is dropped and counted as a hallucination.
Test the reviewerCatch rate, false alarms, escapes and minutes, on planted bugs and on mutants nobody chose.
